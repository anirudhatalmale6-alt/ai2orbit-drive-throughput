One-time setup — how to get the Client ID (2 minutes)
  1. Go to Google Cloud Console → APIs & Services → Credentials.
  2. Enable the Google Drive API (APIs & Services → Library → Drive API → Enable).
  3. Create OAuth client ID → type Web application.
  4. Under Authorized JavaScript origins add this exact site: https://anirudhatalmale6-alt.github.io
  5. Copy the Client ID it gives you and paste it in the box above. No client secret needed (browser token flow).
  6. On the OAuth consent screen add your own Google account under Test users so it lets you in while the app is unverified.
Scope requested is drive.file — the app only ever sees and touches the files it creates in its own AI2ORBIT_Property folder, never the rest of your Drive.
